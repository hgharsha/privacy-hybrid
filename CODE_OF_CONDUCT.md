# Code of conduct

This project is small and run by one maintainer. These rules apply in issues, discussions, pull requests and any other project space.

## Expected
- Be respectful and assume good faith.
- Give and accept feedback on the work, not the person.
- Keep reports and examples free of real personal data: use synthetic values only.

## Not acceptable
- Harassment, insults, discrimination or personal attacks.
- Publishing someone else's private information.
- Spam, or posting exploit details for an unfixed vulnerability in public (use private vulnerability reporting, see [SECURITY.md](SECURITY.md)).

## Enforcement
The maintainer may edit or remove comments, close threads, and block accounts that break these rules. To report a problem, open a private security advisory on the repository ("Report a vulnerability") or contact the maintainer through their GitHub profile.

Adapted in spirit from the Contributor Covenant (https://www.contributor-covenant.org).
